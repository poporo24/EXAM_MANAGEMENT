Description: This ERD is generated from the actual system database (cca_exam_db_export.sql, 13 tables). exams is the central table: each exam is placed in a room, proctored by an instructor, and linked to a subject. Instructors also own their proctor_availability, any proctor_absence reports, and reliever assignments, while secretaries track paper handling in exam_collection. Login accounts live in users (one table for all roles; proctor accounts link to instructors), and each user receives notifications. Solid lines are enforced foreign-key constraints; dotted lines are institute_id references used by the application but not enforced in the database. exam_settings and system_settings are single-row configuration tables with no relationships.

Description: The context-level DFD shows the five external entities that exchange data with the CCA Exam Management System. The Super Admin manages all user accounts and approves student registrations. The Admin maintains master data, sets the exam period and proctor availability, and generates and edits the schedule. The Secretary records exam paper collection and return for their institute. Proctors receive their assigned schedule and can report absences, and Students register and view their exam timetable.

4. Use Case Diagram

Description: This traditional UML use case diagram shows the actors outside the system boundary and the services (ovals) they use inside it. Student, Proctor, Secretary, Admin, and Super Admin all inherit from the generic User actor (hollow-triangle generalization), so each can log in, change their password, and view notifications. Dashed arrows show «include» relationships (always performed, e.g. generating or editing a schedule always checks conflicts) and «extend» relationships (optional, e.g. resetting a forgotten password from the login screen, or resolving conflicts after schedule generation).
Actor Primary Use Cases
User (generic) Login, Reset Forgotten Password, Change Password, View Notifications
Student Register Account, View Exam Timetable
Proctor View Proctoring Schedule, View Proctoring Hours, Report Absence
Secretary Mark Exam Paper Collected / Returned, View Collection Status (own institute)
Admin Manage Rooms, Faculty, Subjects & Institutes; Import CSV Data; Configure Exam Period; Set Proctor Availability; Generate / Edit Exam Schedule; Assign Relievers; Approve / Reject Students; Generate PDF Reports; Print Section Schedules
Super Admin Manage User Accounts (edit, delete, reset password), Approve / Reject Students
